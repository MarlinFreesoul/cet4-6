# CET4 Section A 选词填空 Real Feedback SOP v0.3

- 版本：v0.3
- 形成日期：2026-10-03
- 前序版本：`CET4-Real-Feedback-复盘SOP-v0.2.md`
- 对应 Skill：`run-cet4-word-bank-cloze`
- 适用题型：CET4 Part III Reading Comprehension Section A（词汇理解／选词填空）
- 当前证据：1 次已深度复盘 baseline；个体诊断与干预效果仍待陌生同型题验证

## 1. 用途与边界

本 SOP 不再是泛化的“英语阅读复盘法”，而是一个题型专用执行协议：只处理 CET4 阅读 Section A 选词填空。

目标是：切换到任意年份、任意套数的同格式新题时，可以直接复用同一条证据链、诊断链和实验链，而不是仅复用某篇文章的答案或知识点。

不直接适用于：

- Listening Section A；
- Reading Section B 长篇匹配；
- Reading Section C 仔细阅读；
- CET6、IELTS 或一般完形填空；
- 已发生结构变化的未来 CET4 题型。

对 CET 应使用“官方考试大纲／题型结构”作为上位约束，不把它混称为中小学意义上的“课标”。

## 2. 题型指纹：先匹配，后套用

当前官方公布格式下，本题型的指纹是：

| 维度 | 约束 |
|---|---|
| 考试 | CET4 笔试 |
| 位置 | Part III Reading Comprehension, Section A |
| 官方名称 | 词汇理解（vocabulary comprehension） |
| 材料 | 1 篇约 200–250 词文章 |
| 空格 | 10 个，常见题号 26–35 |
| 候选 | 15 个，常见 A–O |
| 用词约束 | 根据试卷 directions，每个候选词最多使用一次 |
| 任务 | 根据上下文选词，还原连贯文章 |
| 比重 | 全卷 5% |
| 时间 | 官方 40 分钟属于整个阅读部分，不是 Section A 单独限时 |

只有指纹通过才进入标准流程。如果空格数、候选数、可否重复用词、文章恢复方式或官方说明发生变化，标记 `FORMAT_DRIFT`，暂停自动套用，先重新核对官方文档。

## 3. 把“官方约束”和“实验方法”分开

| 层级 | 内容 | 怎样表述 |
|---|---|---|
| 官方大纲／结构 | 篇幅、空格数、候选数、比重、整个阅读时间、测量目标 | 可称“官方公布” |
| 试卷 directions | 候选词不得重复使用、通读全文等具体说明 | 称“该卷说明” |
| Real Feedback Lab | 槽位签名、答案拓扑、错因代码、最小干预、迁移实验 | 称“我们的诊断／实验方法” |

不得把自建方法写成考试委员会的评分规则。

## 4. 七种实验状态

| 状态 | 进入条件 | 当前主要动作 |
|---|---|---|
| `MATERIAL_CHECK` | 材料刚提供 | 核对题型指纹和唯一身份 |
| `BASELINE_ACTIVE` | 学习者正在独立作答 | 只保护基线和轻量记录 |
| `EVIDENCE_FREEZE` | 已作答，原始证据尚未固定 | 先保存答案、信心、思路和修改 |
| `DIAGNOSIS` | 原始证据与参考答案已具备 | 计分、答案拓扑与因果诊断 |
| `INTERVENTION` | 1–3 个主瓶颈有证据 | 只激活 1–2 个行为改变 |
| `VALIDATION` | 准备验证记忆或迁移 | 区分干预执行率与效果 |
| `CAPTURE` | 一轮证据完整 | 写入报告、生词本、学习者模型和下一实验 |

在 `BASELINE_ACTIVE` 中遇到可能泄露答案的求助，优先回应：

> 先留下真实反馈，做完再拆。

## 5. 七道门禁

### G0｜题型与材料身份

记录：

`year-month / set与来源 / CET4-RC-Section-A / 26–35 / 开头词`

必须拥有完整文章、10 个空和 15 个候选。套号不确定时，用开头词和题号定位，不猜。

### G1｜基线完整性

记录答案暴露、查词、翻译、词性或结构提示、候选排除、重做、中断和材料错配。标记为：

- `clean-baseline`；
- `partial-baseline`；
- `practice-only`。

### G2｜原始证据冻结

答案公布前至少固定：

- 26–35 原始答案序列；
- 确定／犹豫／猜测／空白；
- 作答范围与有效耗时；
- 选择顺序、修改和被迫选择；
- 第一遍篇章模型以及何时改变；
- 生词、词义疑问、难句和“当时我以为”。

### G3｜参考答案权威层级

使用：`official / publisher / teacher / third-party / agent-inferred / disputed`。

第三方整理不得写成官方标准答案；如果多份答案冲突，暂停对争议空做最终诊断。

### G4｜因果充分性

每个关键错题和不稳定正确题必须还原到：

`结果 → 当时真正使用的线索 → 所需约束 → 断裂点 → 认知机制 → 可训练能力`

“词汇差”“语法差”“粗心”不能单独通过。

### G5｜干预资格

先把逐空机制聚合成 1–3 个主瓶颈，再只激活 1–2 个干预。其余问题进 backlog。

### G6｜迁移可证伪性

下一实验必须使用未做过、指纹匹配的 CET4 Section A，并写出材料、不变条件、变更动作、执行痕迹、过程指标、结果指标、支持与证伪条件。

## 6. 标准执行流程

### Phase 0｜建立实验身份

1. 进行题型指纹检查。
2. 使用年月、套源、题号和开头词生成 Experiment ID。
3. 区分“单独 Section A”和“完整阅读 40 分钟块”，两者耗时不直接类比。

### Phase 1｜运行未污染 baseline

Agent 不解释生词、不拆句、不提示词性、不排除候选、不泄露难度和答案。

首次基线允许学习者使用自然策略，不把新流程在作答前硬塞进去。验证实验才事先声明本轮唯一改变的行为。

### Phase 2｜冻结不可逆证据

优先保存原始答案、信心、选择顺序、修改、首遍篇章模型和当时思路。解析后的“我早就知道”不能回填为 baseline 证据。

### Phase 3｜计分，但不伪造官方报道分

- 报告原始正确率 `x/10`、猜测数和空白数。
- 可说明本题型在当前结构中占全卷 5%。
- 不将每空换算为 710 报道分中的某个固定数值。

### Phase 4｜先做答案拓扑，再逐空讲解

单独计算：

| 指标 | 要回答的问题 |
|---|---|
| 位置正确率 | 候选词是否放在正确空位？ |
| 候选集重合度 | 正确词是否已进入学习者的选择集？ |
| 漏选正确词 | 是真不认识，还是被别的词占位？ |
| 选入干扰词 | 哪个错词进入了最终答案？ |
| 正确词错位 | 词汇可用，但映射到错误槽位吗？ |
| 互换／级联 | 是否一次早期分配造成后续被迫错位？ |

候选集重合度高、位置正确率低，首先指向槽位映射和验证失败，不应自动归结为“总词汇量不足”。

### Phase 5｜还原真实作答时间线

重建：第一遍怎样理解、何时形成主题与立场模型、先做哪些空、每次选择用了什么线索、哪些空是因为候选已被占用而被迫确定、篇章模型改变后有没有回扫。

### Phase 6｜为候选词建立可用地图

记录表层形式、lemma、可能词性、可见词形、已知语境义和信心。不在未看句子前强行为每个词只指定一个中文义。

### Phase 7｜建立槽位签名

每个关键空的完整签名为：

`词性 + 词形 + 句法角色 + 配价／补语 + 搭配 + 精确语境义 + 衔接 + 篇章立场`

限时快速版只问四个问题：

1. 需要什么词性？
2. 需要什么可见形态？
3. 哪些词统领或完成这个空？
4. 整句需要什么精确意义和立场？

深度复盘版再拆有限谓语、主语、从句边界、缩减结构、指代、配价、介词与衔接。

### Phase 8｜用四重独立检查选词

1. **Form**：词性和形态是否成立；
2. **Frame**：句法、配价、补语、介词和搭配是否成立；
3. **Meaning**：还原后的命题是否精确；
4. **Discourse**：是否与相邻句、段落立场和全文模型衔接。

不能仅因为宽泛中文义相关、邻近有积极／消极词、某词是唯一剩余项，就接受候选。

### Phase 9｜篇章模型更新后回扫

后文澄清主题、年代、立场、指代或转折时：

1. 记录“模型更新”；
2. 回到早期暂定空；
3. 独立重读每个完整句；
4. 只在能说出新约束时修改。

### Phase 10｜逐空因果诊断

按以下固定顺序寻找断裂点：

1. 词性；
2. 屈折／派生形态；
3. 句子骨架与从句角色；
4. 配价、及物性、补语、介词与搭配；
5. 精确语境义；
6. 词汇／语法衔接；
7. 段落立场与篇章模型；
8. 候选池一次性分配与独立回读。

常用代码：

- 词汇：`V-UNK` 不认识，`V-RET` 未提取，`V-MIS` 语境义误调用，`CHUNK` 词块；
- 形态与句法：`MORPH`、`SLOT`、`VAL`、`CLAUSE`；
- 篇章与候选：`COH`、`MODEL`、`BANK`、`CHECK`；
- 过程：`STRAT`、`TIME`、`ATT`、`CARE`、`MATERIAL`。

`CARE` 只在知识当时已可稳定提取、推理正确、最终错误纯属抄写／标记且未重复时使用。

### Phase 11｜审计正确题

正确题不等于已掌握：

| 分类 | 判定 |
|---|---|
| `STABLE` | 词义、形态、结构、搭配和篇章理由都可复现 |
| `STRUCTURE_HIT` | 结构命中，但精确词义不可用 |
| `APPROXIMATE` | 方向正确，关系或概念不精确 |
| `ELIMINATION_HIT` | 主要依赖剩余候选 |
| `LUCKY` | 没有可复现依据 |

只有 `STABLE` 可暂记为掌握，其余需要延迟提取或新题复验。

### Phase 12｜聚合瓶颈与最小干预

只有重复出现、造成级联、影响整体模型、能解释多个表层错误，或具有高杠杆且可验证的机制，才升级为主瓶颈。

干预必须写成：

`触发条件 → 执行动作 → 可见痕迹 → 目标机制`

不接受“多背单词”“仔细一点”“多刷题”作为可执行干预。

### Phase 13｜验证并更新学习者模型

- 延迟重做本篇：验证提取，不证明迁移；
- 未见同型题：验证近迁移；
- 先测“有没有执行干预”，再测“干预是否有效”；
- 优先等待两篇未见同型题的重复证据，再把某模式升级为稳定个人规律。

## 7. 从任意新套卷快速启动

每次切换材料，只需完成以下快速入口：

```markdown
## Section A 快速启动

- 年月／套数／来源：
- 开头词：
- 题号：
- 完整文章：是／否
- 10 空：是／否
- 15 候选：是／否
- 不重复用词：是／否
- 范围：单独 Section A／完整阅读块
- 当前状态：MATERIAL_CHECK／BASELINE_ACTIVE／...
- 参考答案来源：尚未公布／...
```

指纹通过后，Skill 会自动进入对应状态，不需要从头重新解释整套方法。

## 8. 每轮固定产物

1. 题型合规检查；
2. 实验身份与基线状态；
3. 原始答案、信心、耗时、行为时间线；
4. 原始正确率与答案拓扑；
5. 关键空因果诊断与正确题审计；
6. 1–3 个主瓶颈、1–2 个最小干预；
7. 下一个可证伪实验；
8. 语境化生词／词块／配价记录；
9. 学习者模型的保留、削弱或替换；
10. 证据边界与未知项。

正式报告标题顺序为：

1. 【题型合规检查】
2. 【实验身份】
3. 【原始假设】
4. 【真实行为】
5. 【真实反馈】
6. 【答案拓扑】
7. 【逐空因果诊断】
8. 【正确答案审计】
9. 【能力诊断】
10. 【证伪】
11. 【最小干预】
12. 【下一实验】
13. 【可迁移经验】

## 9. 当前个体化模型

当前只有 2026 年 6 月第 1 套 Section A 一个深度样本，因此以下均为待验证假设：

1. 正确候选的识别可能强于精确槽位映射；
2. 全文模型在后半段才变清晰，但模型更新后缺少系统回扫；
3. 词性／形态、配价／搭配、精确语境义与独立整句验证，可能比原始总词汇量更直接地限制本题型；
4. “遇到不确定句就做句式还原”与“槽位签名 + 完整句独立回读”是当前两个激活干预。

除非陌生题证据改变上述判断，不随意新增第三个干预。

## 10. 学习节奏

以“一个完整实验”为单位，而不是机械打卡：

`陌生同型题 → 冻结证据 → 答案拓扑与因果诊断 → 1–2 个干预 → 延迟提取 → 陌生近迁移 → 更新规则`

间隔提取只针对真题暴露的语境义、词块、配价框架和阅读动作，不自动转化成每日固定背词量。

## 11. 停止深挖条件

同时满足以下条件就停止继续增加解释：

- 答案拓扑已知；
- 关键错题和不稳定正确题都有有证据的原因或明确的未知；
- 1–3 个瓶颈已解释主要模式；
- 1–2 个干预具有可观察执行痕迹；
- 下一篇未见 Section A 可以支持或证伪假设；
- 继续讲解已不会改变干预或实验设计。

## 12. 版本规则

- v0.3 取代 v0.2 成为 Section A 选词填空当前执行版；v0.1、v0.2 保留为泛化方法的历史版。
- 新篇章只更新实验报告和学习者模型，不会因一道题自动升级 SOP。
- 只有新证据改变题型指纹、门禁、错因分类、干预选择或验证方法时，才升级 SOP。
- Skill 是 Agent 执行层，SOP 是项目审计层，两者的题型边界和核心规则必须一致。
- “任意年份任意套卷可复用”仅指通过当前题型指纹的材料，不是对未来格式永不变的承诺。
