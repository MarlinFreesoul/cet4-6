# CET4 Real Feedback 复盘 SOP v0.1

- 版本：v0.1
- 形成日期：2026-09-30
- 来源：Stage 01 首次 Section A baseline
- 适用范围：CET4 真题复盘；可扩展到 CET6、IELTS 阅读和其他复杂技能学习
- 核心闭环：假设 → 行动 → 原始反馈 → 底层诊断 → 最小干预 → 新实验 → 验证 → 方法沉淀

## 1. SOP目标

本 SOP 不以“做过多少题”为目标，而要回答：

1. 学习者在真实任务中实际做了什么？
2. 结果由哪个最底层机制产生？
3. 下一轮只改变什么？
4. 怎样用新数据证伪或确认判断？
5. 哪些经验能够迁移到下一题型和下一学习领域？

## 2. 角色分工

### 学习者

- 在无提示条件下完成任务；
- 保存原始答案，不事后美化；
- 报告犹豫、猜测、生词、难句、注意力和策略；
- 用“当时脑中发生了什么”复述，而非用答案倒推合理解释；
- 执行最小干预并参加下一实验。

### 复盘 Agent

- 测试前不泄露技巧、难度、词义和答案；
- 先固定证据，再公布答案；
- 区分事实、推断和待验证假设；
- 对错题和正确题都检查推理路径；
- 把“粗心、词汇差、语法差”继续拆到底层机制；
- 只选1–3个主瓶颈和少数干预；
- 把记录、词汇与 SOP 版本化保存。

## 3. Phase 0｜唯一标识材料

开始前建立 Test ID：

`考试年月 / 套号来源 / Part / Section / 题号 / 开头句`

示例：

`2026-06 / 第1套（资料标注）/ Part III / Section A / 26–35 / One of the biggest controversies...`

规则：

- 不使用“阅读第一题”“第一篇”作为唯一标识。
- 套号冲突时，以题号和开头句为准。
- 记录答案来源及其是否为第三方整理。
- 不提前打开解析。

## 4. Phase 1｜Baseline 锁定

测试期间：

- 不查词；
- 不问技巧；
- 不接收提示；
- 不查看答案；
- 尽量按真实考试时间完成；
- 记录应轻量，不得严重打断作答。

最低记录：

- 实际开始时间；
- 实际结束时间；
- 原始答案；
- 空白题；
- 犹豫题；
- 猜测题；
- 明确不认识的词；
- 读不懂的句子。

## 5. Phase 2｜冻结原始证据

**答案公布之前**必须保存：

- 原始答案序列；
- 每题状态：确定／犹豫／猜测／空白；
- 作答顺序与策略；
- 是否改过答案；
- 实际耗时；
- 当时的文本标记或草稿。

如果原始答案未冻结，暂停答案讲解。否则会发生记忆污染，无法还原真实过程。

## 6. Phase 3｜只做第一层计分

先记录：

- 正确率；
- 每题正误；
- 用时；
- 空白和猜测。

但此时不立刻布置训练。

进一步分析“答案拓扑”：

- 正确答案词是否已经进入候选池？
- 是不知道正确候选，还是放错槽位？
- 是否出现成对互换、连锁错位？
- 错误集中在哪一段、哪一类结构？
- 是否因为前一个选择占用了后一个答案？

总分是表象；错误分布才开始具有诊断价值。

## 7. Phase 4｜还原真实行为

让学习者按时间顺序复述：

1. 第一遍如何阅读？
2. 何时开始理解文章？
3. 先做哪些题，为什么？
4. 每个选择依赖什么线索？
5. 哪一步出现不确定？
6. 是否回读完整句子？
7. 是否利用篇章立场？
8. 是否因候选词已被使用而被迫选择？

要求：

- 使用“当时我以为……”；
- 不允许把答案解析改写成自己的原思路；
- Agent 只追问证据，不急着教学。

## 8. Phase 5｜逐题因果诊断

每题填写六个字段：

| 字段 | 内容 |
|---|---|
| 原始选择 | 当时填了什么 |
| 真实线索 | 当时依据什么 |
| 正确约束 | 本题真正要求什么 |
| 断裂位置 | 哪一步没有成立 |
| 错误代码 | 属于哪一类机制 |
| 证据等级 | 已确认／较可能／待验证 |

推荐错误代码：

- V-UNK：单词完全不认识；
- V-RET：认识但未提取；
- V-MIS：词义调用错误／近义混淆；
- CHUNK：搭配或词块未建立；
- MORPH：词形、主谓一致、分词问题；
- SLOT：词性或句法槽位错误；
- VAL：动词配价、及物性或介词框架；
- CLAUSE：从句层级、指代或省略未还原；
- LOGIC：篇章立场、转折、因果或回指错误；
- OPTION：候选词互相干扰或被前题占用；
- TIME：时间压力；
- ATT：注意力；
- CARE：纯操作性粗心；
- MATERIAL：套题或答案材料歧义。

“粗心”只有在学习者知道规则、当场也能稳定解释、且错误由抄写／漏看等操作造成时才使用。

## 9. Phase 6｜审计正确答案

每个正确答案分类：

1. **稳定正确**：词义、句法、搭配和语境都能解释；
2. **结构命中**：靠词性或结构选对，但不懂准确词义；
3. **近似推断**：方向接近，但概念理解不精确；
4. **排除命中**：依靠剩余选项得到；
5. **偶然猜中**：没有可复现依据。

只有“稳定正确”可暂记为已掌握；其余都进入待验证列表。

## 10. Phase 7｜句式还原与槽位签名

### 句式还原八步

1. 找有限谓语、助动词和系动词；
2. 为每个谓语找主语；
3. 判断从句边界与连接词身份；
4. 回溯代词先行词；
5. 恢复省略；
6. 检查动词配价；
7. 暂时移开修饰语，读取主干；
8. 复原整句并回读。

### 槽位签名

填词前标记：

`词性 + 词形 + 语态／时态 + 配价 + 介词／补语 + 语义角色 + 篇章立场`

候选词必须通过四检：

1. 语法成立；
2. 搭配自然；
3. 句意准确；
4. 篇章逻辑一致。

不能因为某词已在前题使用，就把剩余词勉强放入当前空。

## 11. Phase 8｜知识捕获

### 生词条目

- 卷面形态；
- lemma；
- 词性／形态环境；
- 当前语境义；
- chunk／valency frame；
- 当时误解；
- 掌握状态；
- 延迟提取提示。

### 优先记录的单位

优先级通常是：

`完整框架 > 词块 > 单词孤义`

例如：

- `squeeze X from Y`
- `in an effort to do`
- `take X into account`
- `typically use A as B`
- `with + NP + complement`

## 12. Phase 9｜聚合瓶颈

把逐题原因聚合成1–3个高杠杆瓶颈。

入选条件：

- 在多题重复出现；或
- 单次出现但影响整个篇章；或
- 能解释多个表面错误；或
- 修改后容易通过新题验证。

不得把所有发现同时列为训练任务。

## 13. Phase 10｜设计最小干预

每项干预必须是可执行行为，而不是口号。

不合格：

- 加强词汇；
- 提高语法；
- 更加细心。

合格：

- 不确定句先圈有限谓语并逐个匹配主语；
- 每个空先写槽位签名；
- 填完后用完整句独立验证，不依赖剩余选项；
- 篇章模型形成后回扫前文一次。

一轮优先改变1–2个因素。

## 14. Phase 11｜设计下一实验

区分：

### 延迟提取

验证本次学到的内容能否被再次取出。不能证明迁移。

### 陌生材料迁移

使用未做过的同类型材料，验证干预是否有效。

下一实验必须写明：

- 新材料；
- 保持不变的条件；
- 唯一改变的动作；
- 记录指标；
- 什么结果支持假设；
- 什么结果会证伪假设。

至少观察：

- 正确率；
- 实际耗时；
- 句法无效答案数；
- 正确候选错位数；
- 猜测和犹豫数；
- 干预执行率。

不要凭一次波动宣布方法有效，尽量用两个陌生样本观察趋势。

## 15. Phase 12｜输出标准报告

每轮最终报告固定为：

1. 【原始假设】
2. 【真实行为】
3. 【真实反馈】
4. 【能力诊断】
5. 【证伪】
6. 【最小干预】
7. 【下一实验】
8. 【可迁移经验】
9. 【证据边界】
10. 【项目更新】

## 16. 深度复盘的停止条件

满足以下条件就停止继续解释，进入下一实验：

- 原始行为已还原到足以解释主要错误；
- 每个关键错题和不稳定正确题都有原因；
- 已聚合出1–3个主瓶颈；
- 已选定1–2项最小干预；
- 下一实验能验证或证伪；
- 词汇和方法已保存。

如果继续解释只会增加知识点、不能改变干预或实验设计，就应停止。

## 17. 项目制学习节奏

一个完整实验周期：

1. 真实任务；
2. 冻结证据；
3. 深度诊断；
4. 知识捕获；
5. 延迟提取；
6. 陌生材料迁移；
7. 更新 SOP。

这适合集中式 Deep Work，不要求机械式每日打卡。间隔复习的对象不是“每天背固定数量的词”，而是本轮真正暴露且尚未稳定提取的结构与词块。

## 18. 版本规则

- SOP 文件使用版本号；
- 每次只有被新证据支持的变化才升级；
- 单次题目经验写入实验报告，不立刻当成普遍规律；
- 至少两轮迁移实验重复出现，才提升为较稳定的个人学习规律；
- 保留旧版本或 Git 历史，避免事后改写实验结论。
