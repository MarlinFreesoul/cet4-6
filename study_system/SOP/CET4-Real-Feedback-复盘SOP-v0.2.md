# CET4 Real Feedback 复盘 SOP v0.2

- 版本：v0.2
- 形成日期：2026-09-30
- 前序版本：v0.1
- 来源：Stage 01 首次 Section A baseline 及其元复盘
- 当前证据：完成一次 Section A 深度复盘；干预效果尚未经过陌生材料迁移验证
- 对应 Skill：`run-real-feedback-lab`

## 1. v0.2解决什么问题

v0.1 已经定义了完整复盘流程，但仍可能被执行成一张很长的清单。v0.2 增加四个强制机制：

1. **状态机**：先判断实验目前处于哪个阶段，避免提前教学或提前下结论。
2. **阶段门禁**：证据未冻结，不进入答案讲解；因果链不充分，不进入训练设计。
3. **证据等级**：区分观察事实、学习者追述、Agent 推断和待验证假设。
4. **干预—指标配对**：每个干预都必须留下可观察痕迹，并能被下一实验支持或证伪。

因此，这套 SOP 的目标不再只是“把题讲透”，而是稳定地产生可信的个人学习证据。

## 2. 核心闭环

`真实任务 → 冻结证据 → 还原行为 → 因果诊断 → 聚合瓶颈 → 最小干预 → 延迟提取 → 陌生迁移 → 更新方法`

禁止退化为：

`做题 → 对答案 → 补知识点 → 继续刷题`

## 3. 六种实验状态

| 状态 | 定义 | Agent 的主要动作 |
|---|---|---|
| `BASELINE_ACTIVE` | 学习者仍在独立完成任务 | 保护基线，只记录，不教学 |
| `EVIDENCE_FREEZE` | 已完成，但原始证据尚未固定 | 保存答案、信心、猜测、顺序与当时思路 |
| `DIAGNOSIS` | 原始证据和参考答案已经具备 | 计分、分析答案拓扑、还原行为和因果链 |
| `INTERVENTION` | 主要因果已经足够清楚 | 聚合瓶颈，只选择1–2个行为改变 |
| `VALIDATION` | 正在进行延迟提取或陌生材料实验 | 区分干预执行率与干预有效性 |
| `CAPTURE` | 本轮结论需要保存和版本化 | 形成报告、词汇记录、实验合同与方法更新 |

如果仍处于 `BASELINE_ACTIVE`，统一优先提醒：

> 先留下真实反馈，做完再拆。

## 4. 六道阶段门禁

### G0｜材料身份门

使用以下字段唯一标识材料：

`日期 / 资料来源与套号 / Part或任务类型 / Section / 题号 / 开头句或其他指纹`

“阅读第一题”“第一篇”不能作为唯一标识。材料身份不清时暂停计分。

### G1｜基线完整性门

记录是否发生：

- 答案暴露；
- 词义解释；
- 策略提示；
- 难度暗示；
- 查词或外部检索；
- 重复做题；
- 计时中断；
- 套题或版本误认。

据此标记：

- `clean-baseline`：没有已知污染；
- `partial-baseline`：部分表现仍可用于独立判断；
- `practice-only`：可以学习，但不能再作为基线。

### G2｜原始证据门

答案公布前至少冻结：

- 原始答案或作品；
- 确定、犹豫、猜测、空白；
- 实际开始与结束时间；
- 作答顺序和策略；
- 修改记录；
- 明确生词、难句或卡点；
- “当时我以为……”的思路。

如果完整记录会干扰真实表现，宁可轻量记录，不为追求完美数据破坏任务。

### G3｜因果充分门

关键错题和不稳定正确题必须至少还原到：

`可观察结果 → 当时决策 → 漏用或误用的约束 → 认知机制 → 可训练能力`

“不会”“词汇差”“语法差”“粗心”均不能作为终点。

### G4｜干预资格门

只有当逐题问题已经聚合为1–3个主瓶颈，才设计干预。每轮只激活1–2项，其余进入 backlog。

### G5｜可证伪门

下一实验必须写明：

- 假设；
- 新材料；
- 保持不变的条件；
- 唯一改变的动作；
- 干预执行痕迹；
- 结果指标；
- 什么结果支持假设；
- 什么结果会证伪或要求修改假设。

## 5. 证据等级

| 等级 | 定义 | 示例 |
|---|---|---|
| `OBSERVED` | 有原始答案、照片、草稿或直接记录 | 原始答案序列 |
| `REPORTED` | 学习者事后追述 | “第三段才理解文章主题” |
| `INFERRED` | 多项证据共同支持的解释 | 候选识别强于槽位映射 |
| `UNVERIFIED` | 尚待下一实验验证的假设 | 槽位签名能改善陌生题表现 |

规则：

- 不把 `REPORTED` 写成 `OBSERVED`；
- 不把 `INFERRED` 写成永久人格或能力特征；
- 不把一次讲解后的理解写成迁移成功；
- 保留矛盾证据，不为了叙事完整而强行消除。

## 6. 标准执行流程

### Phase 0｜确认材料

建立 Experiment ID，核对题号、开头句和答案来源。第三方答案必须明确标注，不能称为官方答案。

### Phase 1｜运行真实任务

保持封闭环境。Agent 不提示词义、技巧、考点、难度和答案。过程记录不得显著破坏正常作答。

### Phase 2｜冻结证据

优先保存不可逆的信息：原始答案、当时信心、猜测、顺序、改动和真实思路。不能用答案公布后的合理化解释替代。

### Phase 3｜第一层计分与答案拓扑

先记录正确率、耗时、猜测和空白，再分析：

- 正确候选是否进入过学习者候选池；
- 正确候选是缺失，还是进入了错误槽位；
- 是否出现成对互换；
- 是否由一个早期选择引发连锁错位；
- 是否有一个额外干扰项替代了遗漏答案；
- 错误是否集中在同一结构、段落或作答阶段。

总分描述结果，答案拓扑开始解释结果。

### Phase 4｜按时间还原真实行为

还原：第一遍如何读、何时形成篇章模型、先做什么、每个选择依赖什么、哪里开始不确定、是否回读、是否因为候选已被占用而被迫选择。

复盘使用“当时我以为……”，不使用“看完解析以后我应该……”冒充原始思路。

### Phase 5｜逐项因果诊断

每个关键项目记录：

| 字段 | 内容 |
|---|---|
| 原始反应 | 当时选择或行为 |
| 信心状态 | 确定、犹豫、猜测或空白 |
| 真实线索 | 当时实际使用了什么 |
| 正确约束 | 真正需要满足什么 |
| 断裂点 | 哪一步失效 |
| 错误代码 | 最底层可训练机制 |
| 证据等级 | OBSERVED / REPORTED / INFERRED / UNVERIFIED |

主要代码：

- `V-UNK` 不认识；`V-RET` 未提取；`V-MIS` 词义调用错误；
- `CHUNK` 词块；`MORPH` 词形；`SLOT` 句法槽位；`VAL` 动词配价；
- `CLAUSE` 从句、指代、省略；`LOGIC` 篇章逻辑；
- `OPTION` 候选互扰；`STRAT` 策略机制；
- `TIME` 时间；`ATT` 注意；`CARE` 纯操作粗心；`MATERIAL` 材料歧义。

`CARE` 只有在规则当时可稳定提取、推理本身正确、错误纯属抄写或漏标且未重复出现时才能使用。

### Phase 6｜审计正确答案

正确题分为：

1. `STABLE`：词义、结构、逻辑和理由均稳定；
2. `STRUCTURE_HIT`：依靠词性或结构命中，但词义不准；
3. `APPROXIMATE`：方向接近，概念并不精确；
4. `ELIMINATION_HIT`：主要依靠剩余候选；
5. `LUCKY`：没有可复现依据。

只有 `STABLE` 暂记为掌握，其余仍进入待验证集合。

### Phase 7｜知识与结构还原

对于难句执行：

1. 找有限谓语、助动词和系动词；
2. 给每个谓语寻找主语；
3. 标记从句边界和连接词身份；
4. 回溯代词先行词；
5. 恢复省略或简化结构；
6. 检查动词配价；
7. 暂时移开修饰语；
8. 重建命题并放回篇章。

Section A 的槽位签名为：

`词性 + 词形 + 时态/语态 + 配价 + 介词/补语 + 语义角色 + 篇章立场`

候选必须同时通过语法、搭配、精确句义和篇章逻辑四检。

### Phase 8｜聚合瓶颈

某机制满足以下任一条件，才可能成为主瓶颈：

- 多题重复；
- 造成连锁错误；
- 影响整篇模型建立；
- 能解释多个表面问题；
- 干预后容易用新题验证。

最终只保留1–3个主瓶颈。

### Phase 9｜选择最小干预

候选干预按0–2分评估：

- 重复频率；
- 解释范围；
- 是否留下可观察痕迹；
- 迁移价值；
- 成本，低成本得高分。

每个干预必须写成：

`触发条件 → 执行动作 → 可见痕迹 → 目标机制`

例如：

`当两个候选语义都似乎合理 → 写槽位签名 → 划掉词形、配价或补语不成立者 → 减少正确候选错位。`

### Phase 10｜设计验证实验

区分：

- **延迟提取**：同一材料，验证能否再次取出；不能证明迁移。
- **近迁移**：陌生但同题型、相近难度的材料；检验干预是否有效。
- **远迁移**：结构不同但相关的任务；只在近迁移已有支持后进行。

同时测量：

1. **执行率**：该做干预时是否真正做了；
2. **有效性**：执行后目标错误是否下降，时间成本是否可接受。

若没有执行干预，不能据此判断干预无效。

### Phase 11｜沉淀资产

保存：

- 原始证据；
- 正式实验报告；
- 语境化词汇与词块；
- 瓶颈与干预 backlog；
- 下一实验合同；
- SOP 版本变化。

生词优先记录完整框架和形态环境，而不是孤立中文释义。讲解完成只能标记为 `explained`，经过延迟提取后才是 `retrieved`，在陌生材料中再次调用后才是 `transferred`。

## 7. 下一实验合同

每次必须填写：

```markdown
- 假设：
- 材料与唯一标识：
- 保持不变：
- 唯一改变：
- 执行痕迹：
- 过程指标：
- 结果指标：
- 支持条件：
- 证伪/修改条件：
- 污染处理：
```

对 Section A 可优先观察：正确率、实际耗时、语法无效答案、正确候选错位数、首个错误后的连锁长度、猜测数、干预机会和实际执行次数。

## 8. 固定报告结构

1. 【实验身份】
2. 【原始假设】
3. 【真实行为】
4. 【真实反馈】
5. 【逐项因果诊断】
6. 【正确答案审计】
7. 【能力诊断】
8. 【证伪】
9. 【最小干预】
10. 【下一实验】
11. 【可迁移经验】
12. 【证据边界】
13. 【项目更新】

正式记录使用机器可检查的元数据：Experiment ID、phase、baseline status、evidence frozen、answer authority、主瓶颈数量、干预数量和下一实验类型。

## 9. 深度复盘停止条件

满足以下条件即停止继续讲解：

- 主要行为链已经还原；
- 关键错题和不稳定正确题都有原因或明确的未知；
- 已形成1–3个主瓶颈；
- 已选定1–2个可观察干预；
- 下一实验可以支持或证伪；
- 继续解释只会增加知识，不会改变干预和实验设计。

## 10. 适配 Deep Work 的节奏

以“一个完整实验”而不是“连续打卡天数”作为学习单位：

`真实作答 → 一次深度诊断 → 少数干预 → 延迟提取 → 两个陌生样本观察趋势 → 更新规则`

间隔复习针对本轮真实暴露的结构、词块和误判，不设机械的每日固定词数。未被当前主瓶颈选中的问题保留在 backlog，避免一次启动十项训练。

## 11. 当前个体化假设

以下结论只来自首次 Section A，仍是待验证假设：

1. 篇章整体理解形成晚于局部选择，形成后缺少系统回扫。
2. 正确候选识别能力可能明显高于槽位映射与独立验证能力。
3. 句式还原、槽位签名和整句独立回读可能是高杠杆干预。
4. 精确语境义、词块和配价可能比原始词汇量更直接地限制本题型。

下一轮不得把这些当作固定能力画像；必须使用陌生 Section A 继续证伪。

## 12. 版本规则

- v0.2 取代 v0.1 成为当前执行版本，v0.1 作为历史记录保留。
- 单题经验只能进入实验报告，不能直接升级为普遍规则。
- 同一机制至少在两个陌生样本中重复出现，才可升级为较稳定的个人规律。
- SOP 只有在新证据改变流程、门禁、分类或实验设计时才升级。
- Skill 与 SOP 的核心规则必须保持一致；Skill 是 Agent 执行层，SOP 是项目审计层。
