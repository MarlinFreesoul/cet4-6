# CET4 两周学习系统

本目录是一套从现有资料出发、可直接执行的 14 天四级笔试训练系统。它不把缺失资料补写成“已覆盖”，也不把第三方解析称为官方答案。

## 从这里开始

1. 先读 [`四级两周学习系统.md`](四级两周学习系统.md)，确认考试目标、概念图、每日安排和缩放规则。
2. 打开 [`CET4_两周学习系统.xlsx`](CET4_两周学习系统.xlsx)，先完成“导学题”，不要提前打开真题答案。
3. 做题时只看工作簿“题库”；提交后再看“答案解析”。
4. 每天结束时在“14天日历”和“进度”记录实际分钟、正确率、错误代码和下一次复习日。
5. 详细证据边界见 [`来源与覆盖审计.md`](来源与覆盖审计.md)。

## 已确认的执行参数

- 每日实际弹性容量：至少 2 小时；计划保底量按用户要求设置为 **每天 0.5 小时**。
- 计划考试日：**2026-12-12（用户提供；最终以官方公告与准考证为准）**。
- 目标：主目标 **CET4 630+**，冲刺 **650+**，长期衔接 CET6 与 IELTS。
- 当前状态：尚未开始第一次刷题；前 7 天先完成考试大纲导学，之后再进入首轮刷题。
- 课堂讲义、指定阅读、课程题集、历次小测：用户确认均无；《全国大学英语四、六级考试大纲》作为课程标准与命题边界。

## 资料身份

- 官方目标与题型：教育部教育考试院 CET 官网。
- 训练卷：工作区中标注为 2025/12 与 2026/06 的 CET4 卷。
- 答案与解析：懒笔记第三方整理，**不是全国大学英语四、六级考试委员会公布的官方标准答案**。
- 听力：第 1、2 套有本地 MP3；第 3 套与第 1 套共用听力的说法来自资料页，未另造音频。
