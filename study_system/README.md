## 从这里开始

1. 进行真实测试前，只确认材料身份并锁定 baseline，不提前查看词义、技巧和答案。
2. 完成后先冻结原始答案、信心、猜测、耗时和“当时我以为”的思路，再进入讲解。
3. 复盘使用当前 SOP；旧“两周学习系统”和工作簿仅作为计划与资料参考，不覆盖真实实验数据。
4. 每轮把逐题问题聚合成1–3个瓶颈，只激活1–2个最小干预。
5. 使用延迟提取验证记忆，使用未做过的同类型材料验证迁移。
6. 详细资料边界见 [`来源与覆盖审计.md`](来源与覆盖审计.md)。

## 已确认的执行参数

- 每日实际弹性容量：至少 2 小时；计划保底量按用户要求设置为 **每天 0.5 小时**。
- 计划考试日：**2026-12-12（用户提供；最终以官方公告与准考证为准）**。
- 目标：主目标 **CET4 630+**，冲刺 **650+**，长期衔接 CET6 与 IELTS。
- 当前状态：已完成首次 Section A baseline（4/10）；初步瓶颈为句式还原、槽位匹配与精确词义／词块调用。诊断尚待陌生材料迁移验证。
- 当前干预：句式还原；槽位签名与完整句独立验证。其他问题进入 backlog，不同时展开。
- 课堂讲义、指定阅读、课程题集、历次小测：用户确认均无；《全国大学英语四、六级考试大纲》作为课程标准与命题边界。

## 资料身份

- 官方目标与题型：教育部教育考试院 CET 官网。
- 训练卷：工作区中标注为 2025/12 与 2026/06 的 CET4 卷。
- 答案与解析：懒笔记第三方整理，**不是全国大学英语四、六级考试委员会公布的官方标准答案**。
- 听力：第 1、2 套有本地 MP3；第 3 套与第 1 套共用听力的说法来自资料页，未另造音频。
