# CET4-6 基础资料库

面向个人学习与备考的大学英语四、六级真题基础资料库，公开托管以便跨设备和云端会话访问，覆盖：

- 2024/12/第1套、第2套、第3套
- 2025/6/第1套、第2套、第3套
- 2025/12/第1套、第2套、第3套
- 2026/6/第1套、第2套、第3套

四级与六级合计 24 个套卷单元。每个单元至少包含：

- `真题.pdf`
- `答案解析.pdf`

有公开听力源的套卷还包含 `听力.mp3`。通常同一考次第 3 套没有单独听力文件，因此不以预测音频或不明来源文件补位。

## 来源与证据边界

- 下载页与文件直链记录在 [`sources/SOURCES.csv`](sources/SOURCES.csv)。
- 文件完整性校验值记录在 [`sources/SHA256SUMS`](sources/SHA256SUMS)。
- 主要资料源为 [懒笔记英语真题](https://english-exam.lazynote.cn/)，无需登录即可下载整卷 PDF；听力使用其公开 HLS 音频并转为 MP3。
- 全国大学英语四、六级考试委员会不公开标准答案；仓库中的答案与解析属于第三方整理的参考答案，可能存在争议或修订，不应标记为官方标准答案。
- 本仓库以个人学习与备考为主要用途，公开托管不表示资料版权或再授权发生转移。资料版权归各自权利人所有，请勿用于商业用途；如权利人认为内容需要调整或移除，请通过仓库 Issue 联系。

## 更新资料

需要重新拉取或补全文件时：

```bash
./scripts/download_materials.zsh
./scripts/verify_materials.zsh
```

仓库使用 Git LFS 管理 PDF 与 MP3。首次克隆前请安装 Git LFS，并执行 `git lfs install`。

下载脚本依赖：`curl`、`rg`、`ffmpeg`、`file`、`shasum`；若安装了 `pdfinfo`，验证脚本还会检查 PDF 页数。
