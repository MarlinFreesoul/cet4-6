# Minimal intervention and validation design

## Convert a diagnosis into an action

Write every intervention as:

`trigger → action → visible trace → expected mechanism`

Example:

`When two candidates both seem semantically possible → write the slot signature → cross out any candidate that fails form, valency, or complement structure → reduce misplaced viable candidates.`

Reject interventions such as “improve vocabulary,” “read carefully,” or “practice grammar.” They do not identify a decision point or observable behavior.

## Rank candidates

Score each proposed intervention from 0 to 2 on:

- **recurrence:** how often the cause appeared;
- **reach:** how many outcomes it can explain;
- **observability:** whether execution leaves evidence;
- **transfer value:** whether it should help outside the reviewed item;
- **cost:** reverse score; low time and cognitive cost receives 2.

Use the score to support judgment, not replace it. Select no more than two interventions. Preserve the rest in a backlog.

## Separate execution from efficacy

Measure two questions independently:

1. **Execution:** Did the learner perform the new action at the intended trigger?
2. **Efficacy:** When performed, did the target error decrease without unacceptable time cost?

Possible interpretations:

| Execution | Outcome | Interpretation |
|---|---|---|
| low | unchanged | Cannot judge efficacy; simplify or cue the action |
| high | improved | Supports the intervention hypothesis |
| high | unchanged | Mechanism may be wrong or action insufficient |
| high | worse | Check cognitive load, incorrect application, and material mismatch |

## Choose the experiment type

### Delayed retrieval

Use the same material after a delay to test whether learned forms, chunks, structures, or reasoning can be retrieved. Do not claim transfer.

### Near transfer

Use unseen material of the same task type and similar difficulty. Change only the selected intervention when feasible.

### Far transfer

Use a related but structurally different task only after near transfer is plausible. Do not jump from one CET item directly to a general claim about all learning.

## Write the next-experiment contract

Specify:

- hypothesis;
- material and unique identity;
- invariant conditions;
- changed action;
- visible execution trace;
- outcome metrics;
- process metrics;
- support criterion;
- falsification or revision criterion;
- contamination handling.

Prefer two unseen samples before promoting an intervention into a stable personal rule.

## Default metrics for constrained-choice reading

- accuracy;
- active time;
- confidence calibration;
- guesses and blanks;
- grammatically invalid final answers;
- viable candidates placed in wrong slots;
- cascade length after first wrong allocation;
- intervention opportunities;
- intervention executions;
- target-error recurrence.

Use metrics tied to the hypothesis. Do not collect everything merely because it is measurable.

## Adapt to project-based rhythm

Use one complete experiment as the unit of work:

`real attempt → evidence freeze → deep diagnosis → one or two interventions → delayed retrieval → unseen transfer → method update`

Do not require mechanical daily quotas. Use spaced retrieval on the exact structures and chunks exposed by the experiment, while keeping unseen transfer tests sufficiently separated to remain informative.
